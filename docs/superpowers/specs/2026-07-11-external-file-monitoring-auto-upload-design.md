# 外部文件监听与自动上传设计

## 目标

OnetCli 不修改 Zed、Notepad--、Notepad++ 或任何扩展的保存行为。外部编辑器只要把 OnetCli 的本地临时文件真正写盘，OnetCli 就检测变化并上传远端。

## 设计

- 增加默认开启的全局配置 `remote_file_editor.auto_upload_external_changes`。
- 开启时同时使用 `notify` 文件事件和定时轮询；关闭时新会话不创建 watcher、poller 或上传 controller。
- 轮询每 2 秒触发一次，并等待现有 750ms 稳定窗口后检查文件。
- 每次检查先读取本地内容并计算内容指纹；内容未变化时不查询远端、不上传。
- watcher 与轮询同时发现同一次保存时，由最后成功同步的内容指纹去重。
- 内容变化后继续使用既有远端 snapshot 冲突检查、串行同步、pending 合并和通知。
- 远端重新加载写回本地时同步更新内容指纹，避免把刚下载的远端内容再次上传。

## 验收

- 所有外部编辑器统一使用同一监听/轮询上传链路，无 editor ID 特判。
- 自动上传默认开启，旧设置兼容；显式关闭后新会话不上传。
- 未变化的轮询不产生远端请求。
- 保存事件遗漏或原子替换文件时，轮询仍能发现写盘变化。
- 不修改扩展仓库和编辑器配置。
