# Navop 使用說明

Navop 將資料庫、Redis、MongoDB、SSH、SFTP、終端、遠端桌面、Notes、AI 和團隊同步放在同一個原生工作區。

## 目前版本：v0.9.1

[下載 Navop v0.9.1](https://github.com/feigeCode/navop/releases/tag/v0.9.1)

- Markdown 預設以唯讀預覽開啟，可切換到原始碼模式安全編輯；應用程式、終端與 Markdown 現在使用統一主題系統。
- 首頁升級為最近連線儀表板，常駐連線側邊欄支援虛擬化清單、顯示切換、拖曳、分組、複製分享和彈性調整寬度。
- 新增可攜式執行模式、SSH X11 轉發、遠端作業系統圖示識別，以及獨立遠端桌面視窗全螢幕。
- 修正 MongoDB 受限帳號、PostgreSQL 數值精度與 SQLSTATE、終端命令列、RDP 重新連線、分頁寬度和跨平台版面配置等問題。
