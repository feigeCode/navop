# SSH 與終端工作區

Navop 將遠端 SSH 和本機 Terminal 放在統一工作區，支援標籤、分割、廣播輸入、歷史、快捷命令、自訂醒目提示和 Shell integration。命令會直接作用於本機或伺服器，必須持續確認主機與身分。

## 建立 SSH 與本機終端

SSH 支援密碼、私鑰檔、私鑰內容、SSH Agent 和預設 `~/.ssh`；互動驗證伺服器可能要求 MFA。可設定代理與逾時，首次連線先核對主機指紋。失敗時分別檢查使用者、密鑰權限、Agent、MFA 和伺服器政策。

本機 profile 可選系統 Shell、PowerShell、CMD、WSL、Git Bash 或自訂程式；開啟終端時可直接選擇目前工作階段使用的 Profile，並會隱藏本機平台不可用的選項。自訂可執行檔必須可信，不要把密碼放在命令參數。

終端 AI 側邊欄同時支援 SSH 與本機終端，並把目前終端作為預設資源上下文。執行產生的命令前仍要核對 Shell、作業系統、主機與目錄；本機 PowerShell、自訂程式和遠端 Linux Shell 的語法不能混用。

## Agent Hub：程式設計、資源與 Git 協作

Agent Hub 並不是單獨的終端截圖，而是由終端 Agent、工作區資源管理器、Git 變更清單、分支管理與並排 Diff 共同組成的完整功能。它採用成熟 Agent 程式設計工具中常見的組合式工作區，讓程式碼執行、檔案定位和修改審核保持在同一上下文，同時可直接結合 Navop 的本機終端、SSH 工作階段和連線資源。

![Agent Hub 工作區](/images/agent_hub.png)

可在終端旁開啟工作區資源管理器，讓專案檔案樹、目前變更和活動工作階段保持在同一畫面。工作區目錄可手動選擇，也可跟隨終端目前目錄；隱藏檔案和 Git 忽略檔案可分別控制顯示。移動、刪除或編輯前，先確認資源管理器代表本機目錄還是遠端工作階段。

![Agent Hub 分支管理](/images/git_branch.png)

分支面板支援搜尋、重新整理、擷取遠端分支、推送、新增分支，以及切換本機或遠端分支。切換前先儲存或暫存目前修改，確認目標與追蹤關係；擷取遠端分支不代表衝突會自動解決。

![Agent Hub 並排差異](/images/git_diff.png)

從變更列表開啟檔案，可並排比較 HEAD 與工作副本，並使用搜尋、重新載入和差異跳轉逐項檢查。Agent 或腳本修改專案後，先閱讀 diff、執行檢查，再提交；唯讀差異檢視不能取代格式化、型別檢查與測試。

## 標籤與分割

終端可向 Left、Right、Top、Bottom 分割，標籤可拖到其他面板並調整大小。關閉面板前檢查前景工作、編輯器或未完成程序。

重新連線後應核對程序和目錄。長時間工作使用伺服器側會話工具，不要假設 GUI 標籤能保持執行狀態。

## 廣播輸入與貼上保護

廣播只傳送到已選取且開啟的 SSH 終端。逐一檢查主機、使用者和目前目錄，先發送 `pwd` 等唯讀命令。一個錯誤會同時擴散到所有選取伺服器。

非 bracketed paste 的多行貼上和高風險命令會要求確認。右鍵/中鍵貼上及選取自動複製可設定。含換行、管線、重新導向或刪除的剪貼簿內容先在文字編輯器審閱。

## 歷史、快捷命令與醒目提示

歷史依最近、常用和收藏整理。快捷命令可設定名稱、說明、命令、群組、顏色和置頂，並支援搜尋、複製或貼到終端。刪除群組不會刪除其中命令。

自訂正規表示式和預設可標示錯誤或關鍵字，但只提供視覺輔助，不代表命令成功。

## Shell integration 與圖片

Shell integration 可把 SSH 目前目錄同步到檔案管理器，實際效果取決於遠端 Shell。剪貼簿圖片可上傳到 SSH 並插入路徑；上傳前確認目標、權限和敏感性。伺服器監控詳見遠端存取章節。
