# 設定、字型與快捷鍵

設定集中管理外觀、資料庫、終端、遠端編輯、Notes、LLM、MCP、日誌和更新。修改後先在非關鍵會話測試；字型與快捷鍵問題雖通常不破壞資料，卻可能改變顯示與操作。

## 語言、主題與字型

可設定語言、啟動頁、淺色/深色主題或跟隨系統。外觀設定也包含視窗透明度、主題配色、自訂強調色與主題匯入；應用程式與終端主題會統一輸入框、彈出層、捲動條、選取範圍與終端配色。只匯入可信來源，並在常用工作區檢查文字、焦點與選取狀態的對比度。

![統一主題與外觀設定](/images/theme.png)

應用程式、SQL、資料表預覽和終端字型可分別選擇。自訂字型支援 `.ttf`、`.otf`、`.ttc` 和 `.otc`，載入前確認授權與檔案完整性。

缺少字元時可能回退或顯示異常；SQL 與終端適合等寬字型。變更主題後檢查醒目提示和圖表可讀性。

## 資料庫與表格偏好

設定包含連線開啟模式、SQL 自動儲存、最大列數、表格列高和大文字開啟方式。最大列數只限制預覽，不是伺服器權限；提高會增加記憶體和網路使用。自動儲存不會提交交易。

顯示密度不會改變真實欄位值。長文字或二進位資料選擇適合編輯器，提交前查看 SQL 預覽。

## 終端與遠端編輯

本機 Terminal 可選系統 Shell 或可信自訂程式。設定也包含補全、選取複製、右鍵/中鍵貼上、多行確認、高危命令警告與字型。降低防護前先理解 bracketed paste 和剪貼簿風險。

遠端檔案可選內建或擴充提供的外部編輯器、執行路徑和自動上傳；應保留遠端衝突檢查。

## Notes、LLM 與 MCP

Notes 設定選擇本機目錄，更換不會自動搬移舊資料。LLM Provider 管理 API key、URL、模型與預設項，刪除前確認沒有活動 Agent 相依。

MCP 設定控制 Temporary/Persistent、權限檔位與 Tool Exposure。任何放寬都可能增加真實操作，變更後讓用戶端重新連線並檢查工具列表。

## 快捷鍵

快捷鍵依全域、終端、資料庫、表格、遠端編輯、Redis 和 Notes 分類。修改前搜尋既有綁定，並考慮作業系統與輸入法攔截；破壞性操作不應綁定容易誤觸的單鍵。

無效時先檢查焦點、平台、輸入法和衝突，再恢復預設或改用其他組合。

## 日誌與更新

設定可查看日誌路徑、自動檢查和手動更新。日誌可能包含路徑、主機和錯誤上下文，分享前必須遮蔽。更新前儲存工作並結束交易和傳輸，更新後確認擴充相容性。
