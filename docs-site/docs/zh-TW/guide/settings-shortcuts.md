# 設定、字型與快捷鍵

設定中心按領域分為 12 頁：一般、資料庫、終端、SSH、SFTP、AI、Agent、MCP、同步、帳戶、快捷鍵和關於。檔案傳輸、遠端編輯器與 ssh://、sftp://、jms:// 等連結接管分別歸入 SSH、SFTP 等對應頁面。修改後先在非關鍵工作階段測試；字型與快捷鍵問題雖通常不破壞資料，卻可能改變顯示與操作。

## 語言、主題與字型

可設定語言、啟動頁、淺色/深色主題或跟隨系統。外觀設定也包含視窗透明度、主題配色、自訂強調色與主題匯入；應用程式與終端主題會統一輸入框、彈出層、捲動條、選取範圍與終端配色。只匯入可信來源，並在常用工作區檢查文字、焦點與選取狀態的對比度。

![統一主題與外觀設定](/images/theme.png)

應用程式、SQL、資料表預覽和終端字型可分別選擇。終端與資料庫共用「內建 + 自訂 + 系統已安裝」的等寬字型清單。自訂字型支援 `.ttf`、`.otf`、`.ttc` 和 `.otc`，載入前確認授權與檔案完整性。

缺少字元時可能回退或顯示異常；SQL 與終端適合等寬字型。變更主題後檢查醒目提示和圖表可讀性。

## 連線顯示與排序

「設定 → 一般 → 連線顯示」中的「連線排序」控制連線列表順序：預設依名稱自然排序（IP 等數字段以數值比較、忽略大小寫），也可切換為「最近使用優先（LRU）」。該設定同時套用於首頁連線列表、Redis/MongoDB 工作區標籤頁和常駐側欄連線樹，切換後立即生效。

排序只改變顯示順序，不會修改連線本身；整理連線時不要用排序取代命名或分組。

## 資料庫與表格偏好

設定包含連線開啟模式、SQL 自動儲存、最大列數、表格列高和大文字開啟方式。最大列數只限制預覽，不是伺服器權限；提高會增加記憶體和網路使用。自動儲存不會提交交易。

顯示密度不會改變真實欄位值。長文字或二進位資料選擇適合編輯器，提交前查看 SQL 預覽。

## 終端與遠端編輯

本機 Terminal 可選系統 Shell 或可信自訂程式。終端全域預設值在「設定 → 終端」調整，包括字型、主題、補全、選取複製、右鍵/中鍵貼上、多行貼上確認、高危命令提示與終端搜尋。

終端工具側邊欄的「設定」面板只作用於目前工作階段：字型大小、主題等約 20 項變更不會儲存，也不會影響其他終端；面板底部提供「恢復全域預設」。懸浮工具列與自動工作階段日誌的開關也已移到應用程式設定頁。貼上確認同樣提供「開啟設定」與「不再提示」；降低防護前先理解 bracketed paste 和剪貼簿風險。

遠端檔案可選內建或擴充提供的外部編輯器、執行路徑和自動上傳；應保留遠端衝突檢查。

## Notes、LLM 與 MCP

Notes 設定選擇本機目錄，更換不會自動搬移舊資料。LLM Provider 管理 API key、URL、模型與預設項，刪除前確認沒有活動 Agent 相依。

MCP 設定控制 Temporary/Persistent、權限檔位與 Tool Exposure。任何放寬都可能增加真實操作，變更後讓用戶端重新連線並檢查工具列表。

## 快捷鍵

快捷鍵依全域、終端、資料庫、表格、遠端編輯、Redis 和 Notes 分類，支援清除綁定與停用系統快捷鍵（關閉全域熱鍵後，已註冊的系統級組合鍵會一併釋放）。關閉當前頁籤的預設快捷鍵為 Cmd/Ctrl+Shift+W，可在設定中改綁。修改前搜尋既有綁定，並考慮作業系統與輸入法攔截；破壞性操作不應綁定容易誤觸的單鍵。

無效時先檢查焦點、平台、輸入法和衝突，再恢復預設或改用其他組合。

## 日誌與更新

設定可查看日誌路徑、自動檢查和手動更新。更新通道在「設定 → 關於」切換：穩定版或測試（Beta）；鏡像來源可選自動、Cloudflare、CNB 或 GitHub，網路受限時再手動指定。日誌可能包含路徑、主機和錯誤上下文，分享前必須遮蔽。更新前儲存工作並結束交易和傳輸，更新後確認擴充相容性。
