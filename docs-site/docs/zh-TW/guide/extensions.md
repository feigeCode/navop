# 擴充市場與本機擴充

擴充可加入資料庫驅動、ACP Agent、連線匯入、遠端桌面 Provider 和語言套件。擴充程式碼在本機執行，應像其他桌面軟體一樣審查來源、權限、平台與版本相容性。

## 擴充類型

資料庫驅動增加連線類型；ACP Agent 接入外部 Agent；匯入擴充讀取其他應用程式；遠端桌面擴充提供 RDP/VNC；語言擴充加入介面語系。

相容清單中的產品名稱不代表驅動已安裝，建立連線前先檢查市場項目、平台和 Navop 版本。

## 安裝、更新與重新載入

安裝前閱讀發佈者、說明、權限與版本資訊。完成後依提示重新載入擴充或重啟。Navop 會按擴充類型更新相關能力，並讓語言解析器維持按需載入，避免一般擴充變更觸發全部語言 WASM 編譯。更新驅動或 Provider 前先儲存工作，因連線行為可能變更。

異常時先停用再啟用或重新載入，接著檢查日誌和相容版本。正式任務進行中不要更新正在使用的驅動。

## 本機與離線包

開發或受限網路可安裝本機擴充和離線包。核對來源與完整性，本機套件可能未經市場分發檢查；使用非正式資料和獨立工作區測試。

複製時保留 manifest、二進位與資源，離線機器也要準備依賴。升級 Navop 後重新驗證相容性。

## 權限與執行限制

擴充可能依 manifest 存取網路、檔案、連線元資料或渲染資源。只授予所需權限，未知發佈者不應接觸正式憑證。匯入器被拒絕檔案權限後無法讀取部分密碼是預期結果。

WASM 和其他受控執行環境有資源與逾時限制。擴充工作失敗時應檢查輸入、權限、日誌和相容版本，不要無限制放寬資源。

## 解除安裝與問題報告

解除安裝前關閉相依連線、ACP 會話和遠端桌面。移除會在背景執行並顯示目前狀態；完成前不要再次觸發安裝、重新載入或移除。移除通常只刪除能力，不會刪除遠端資料；重新安裝相容擴充後，已存連線可能再次可用。

報告包含 Navop、擴充版本、平台、步驟和遮蔽日誌，不得附上密碼、私鑰、API key、主密鑰或完整匯入檔。
