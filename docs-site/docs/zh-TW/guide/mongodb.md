# MongoDB Explorer

MongoDB Explorer 管理連線、資料庫、集合、文件、索引與驗證規則，並支援 Find、Aggregate、Count 和 Explain。刪除資料庫、集合或文件會直接修改伺服器。

## 安全連線

可使用連線字串，或填寫主機、連接埠和驗證欄位。依部署設定驗證資料庫、逾時和 TLS，也可加入 SSH 通道。副本集與分片環境需要正確探索參數，且網路必須能到達驅動選擇的節點。

先測試再儲存。正式 TLS 應驗證憑證。伺服器選擇逾時可能來自 DNS、拓撲探索、防火牆或驗證來源，不應只提高逾時掩蓋問題。

## 資料庫、集合與文件瀏覽

展開資料庫與集合，輸入 JSON 篩選，並設定排序和分頁。條件必須是有效 JSON 或支援的 Extended JSON，型別要符合 BSON。目前頁搜尋不等於伺服器查詢。

某些物件寫入資料後才真正出現。刪除資料庫或集合不可逆，操作前核對連線、名稱與備份。

## 新增、編輯與刪除文件

以 JSON 形式建立或編輯文件，注意 `_id`、ObjectId、日期、陣列和巢狀物件型別。把特殊 BSON 誤寫成普通字串會改變語意。編輯前載入最新狀態，避免覆蓋其他用戶端修改。

刪除前用相同條件執行 Find 或 Count 確認數量。批次寫入先從小範圍開始，完成後重新查詢重要文件。

## Find、Aggregate 與 Count

Find 用於篩選、投影、排序和分頁；Count 確認規模；Aggregate 用多階段管線進行分組、轉換、關聯與統計。逐一加入 stage 並檢查輸出結構和數量。

正式高峰不要直接執行未知的全集合掃描或大型聚合，先加限制並觀察負載。

## 索引、驗證規則與 Explain

可檢視、新增和刪除索引。建立唯一索引前清除重複值；刪除前確認沒有關鍵查詢依賴。大型集合建索引會消耗 CPU、記憶體和磁碟。

驗證規則會限制後續寫入，先在樣本集合測試 JSON Schema 或運算式。Explain 可顯示索引使用和掃描/回傳文件數，據此調整查詢或索引。
