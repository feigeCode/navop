# SFTP 與遠端檔案編輯

SFTP 檔案管理器支援目錄導覽、收藏、傳輸、權限、解壓縮和遠端編輯。兩側都可在本機儲存與可搜尋的遠端端點間切換，也可直接在兩台遠端伺服器之間複製檔案或目錄。覆寫、刪除、權限修改與自動上傳會立即影響伺服器。

## 導覽目錄與終端協同

瀏覽資料夾、依需要顯示隱藏檔案，並收藏常用路徑。可在目前目錄開啟終端；啟用 Shell integration 後，終端路徑也能同步回檔案管理器。存取仍受遠端帳號權限限制。

新增或重新命名前確認目前路徑。變更執行中的設定檔、腳本或連結可能使服務失效。

## 在遠端端點間複製

使用端點切換器搜尋目標 SSH/SFTP 伺服器，確認兩側顯示的連線、使用者與路徑。伺服器間複製會透過遠端連線直接傳輸檔案或目錄，不會先寫入本機臨時目錄。完成後重新整理目標目錄，檢查大小、權限與必要的校驗值；兩端帳號權限和伺服器策略仍然適用。

## 上傳、下載與佇列

可選擇檔案或資料夾、從桌面拖放或使用剪貼簿上傳；下載前選擇本機目標並檢查磁碟空間。傳輸佇列顯示進度和錯誤，關閉應用程式或連線可能取消進行中的任務。

中斷後比較大小或雜湊並檢查部分檔案，再決定重試，部署包、壓縮檔和備份尤其重要。

## 衝突策略與解壓縮

同名時可選跳過、保留兩者、合併或覆寫。目錄合併只是繼續處理子項，不會智慧合併檔案內容；覆寫前先備份遠端版本。

遠端解壓縮會消耗磁碟並建立大量檔案。不可信壓縮包可能包含危險路徑，應先在隔離位置檢查；解壓衝突也需明確選擇策略。

## 權限與刪除

修改前理解擁有者、群組和其他使用者權限，避免公開私鑰或移除程式執行權。遞迴修改先在小範圍測試。

遠端刪除通常不進本機垃圾桶。先核對完整路徑、數量、備份和執行中程序的影響。

## 內建與外部編輯器

內建程式碼/文字編輯器支援搜尋、取代、軟換行、重新載入和儲存，關閉未儲存內容會提示。遠端檔案被修改或刪除時，先比較兩個版本再重新載入或有意覆寫。

外部編輯器擴充可設定預設程式和路徑。外部儲存後可自動上傳，但 Navop 仍會先檢查遠端變更。自動上傳不是版本控制，重要檔案必須保留備份。
