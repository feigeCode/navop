# 資料表資料瀏覽與編輯

資料頁支援分頁、篩選、複製和列編輯。提交新增、修改或刪除會寫入真實資料庫，送出前必須確認鍵值、篩選條件與環境。

## 瀏覽、分頁與篩選

從資料表或檢視開啟資料頁，以分頁控制載入量。目前頁搜尋只篩選已載入資料，不等同伺服器完整查詢；跨頁篩選和統計應使用 SQL。重新整理會讀取最新狀態。

大型資料表應保持合理頁面大小與最大列數。檢視能否編輯取決於資料庫與定義，唯讀時改用基礎表或明確 SQL。

## 編輯儲存格與特殊值

直接編輯儲存格，長文字、JSON 或多行內容使用大文字編輯器。`NULL` 與空字串意義不同，應使用明確的 NULL 動作，不要用空白輸入猜測。

新增列可從空白開始或複製現有列。複製後必須修改主鍵與唯一欄位；只有欄位和業務規則需要時才產生 UUID。二進位、自動產生或特殊類型可能受驅動限制，提交後重新整理驗證。

## 新增、複製與刪除列

本機變更在提交前仍可撤銷。刪除前檢查數量和主鍵，特別是在排序、分頁或篩選狀態。沒有穩定主鍵的資料表可能無法安全定位單列。

選錯時先放棄待提交變更。正式資料刪除應配合受控 SQL、交易與備份，而不是依賴人工復原。

## SQL 預覽與提交

開啟 SQL 預覽檢查產生的 INSERT、UPDATE、DELETE，包括資料表、欄位、值與定位條件。預覽只能證明產生的語句，無法判斷業務意圖。確認後再提交。

部分失敗時先理解具體語句和交易行為再重試。成功後重新整理，並以主鍵或業務條件查詢驗證。

## 複製與匯出

可複製儲存格、列或結果，並匯出 `.xlsx`、`.csv` 和 `.sql`。檢查欄位、列範圍、編碼、日期與 NULL 表示；試算表軟體可能自動轉換長數字。

匯出檔已離開資料庫權限邊界，敏感資料應存放在受控位置並依規則清除。
