# Redis 工作台

Redis 工作台支援單機、Sentinel 和 Cluster，提供 Key 瀏覽、常見型別編輯、CLI、伺服器資訊和即時診斷。刪除與命名空間清理會立即生效，通常無法恢復。

## 建立 Redis 連線

選擇單機、Sentinel 或 Cluster，填寫節點、連接埠、使用者、密碼和資料庫。需要加密時啟用 TLS，受限網路可使用 SSH 通道。Sentinel 必須提供正確服務名稱；Cluster 用戶端需能存取重新導向後的所有節點位址。

先測試網路與驗證。若尚未安裝 Redis 原生驅動，開啟連線時 Navop 會提示下載安裝；安裝成功後會直接繼續開啟同一連線，不必重新啟動。離線環境應預先準備相容的驅動擴充。正式環境使用受限帳號，並確認掃描、INFO、Slow Log 與 Pub/Sub 等命令權限。

## 搜尋與瀏覽 Key

可對已載入項目做本機篩選，或使用伺服器掃描與 Redis glob 語法 `*`、`?`、`[]`。過寬模式會產生大量結果，應縮小命名空間；活躍實例中的 Key 也可能在掃描期間改變。

選取 Key 後查看型別、TTL、記憶體和長度。修改 TTL 會改變生命週期；重新命名前先檢查目標衝突和應用程式引用。

## 編輯資料型別

String 可修改值；List 可從頭尾加入或刪除；Set 管理成員；Sorted Set 管理成員與 score；Hash 管理欄位和值。提交前確認目前型別、位置和併發更新。

非 UTF-8 值可能以 Raw、Hex 或 Binary 顯示。此類資料不可當一般文字轉換後寫回，應保留原始位元組。大型值也會增加記憶體和網路負載。

## CLI 與診斷

CLI 顯示原始命令與回應。執行 DEL、FLUSH、CONFIG、EVAL 或貼上腳本前重新審閱。Server Info 顯示版本、用戶端、持久化和複寫；Memory、Slow Log、命令統計及即時圖表則協助分析資源和趨勢。

指標必須結合採樣週期與業務負載理解，單次尖峰不等於持續故障。

## Pub/Sub 與刪除

Pub/Sub 可訂閱新訊息，也可依權限發佈測試內容；離線期間沒有歷史補送。正式頻道發佈前確認格式與消費者影響。

單 Key、批次模式或命名空間刪除都可能立即中斷應用。先備份或在測試實例演練，縮小模式，完成後檢查剩餘 Key 和業務狀態。
