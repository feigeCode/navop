# 扩展市场与本地扩展

扩展为 Navop 增加数据库驱动、ACP Agent、连接导入、远程桌面 Provider、语言包、文档渲染器等能力。扩展代码在本机运行，应像安装桌面软件一样审查来源、权限、平台与版本兼容性。

![扩展市场](/images/extension.png)

## 浏览市场与扩展类型

从扩展市场按类型或名称查找组件。数据库驱动增加新的连接类型；ACP Agent 接入外部 Agent；连接导入扩展读取其他应用配置；远程桌面扩展提供 RDP/VNC Provider；语言扩展增加界面语言；文档渲染器处理特定 Notes 或预览格式。

市场条目会说明版本、平台和 Navop 兼容范围。某种连接出现在宣传列表中，不代表未安装驱动时即可创建，应先确认相应扩展已启用。

## 安装、更新与重载

市场安装前阅读发布者、说明和所需权限。安装完成后按提示重载扩展或重新启动应用；新连接类型和设置项可能只有重载后出现。更新前保存工作并阅读变更说明，数据库驱动或 Provider 更新可能改变连接行为。

扩展异常时先尝试禁用、启用或重载，再检查日志和兼容版本。不要在生产任务进行中更新负责当前连接的驱动。

## 本地与离线包

开发者或受限网络环境可以安装本地扩展、离线包。只使用可信来源并核对包完整性；本地安装不会经过市场的全部分发检查。测试扩展应使用非生产数据和独立工作区。

离线环境还需准备扩展自身依赖。复制扩展目录时保留完整清单和资源，不要只移动单个二进制文件。升级 Navop 后重新验证离线扩展兼容性。

## 权限与运行限制

扩展可能访问网络、文件、连接元数据或渲染资源，具体以清单和界面提示为准。只授予功能所需权限，未知发布者不应接触生产凭据。连接导入扩展读取其他应用配置时，系统可能要求额外文件权限；拒绝后部分密码或记录无法导入属于正常结果。

WASM 文档渲染器和其他受控运行时具有资源与超时限制。复杂文档无法渲染时应优化输入或使用可信外部工具，不要通过无限放宽资源限制掩盖扩展问题。

## 卸载与问题报告

卸载前关闭依赖该扩展的连接、ACP 会话和远程桌面。卸载会移除功能入口，但通常不会删除远端数据；已保存连接可能在重新安装兼容扩展后恢复可用。是否保留扩展设置取决于类型和版本。

报告问题时提供 Navop 版本、扩展名称与版本、平台、重现步骤和脱敏日志。不要提交数据库密码、SSH 私钥、API key、主密钥或完整的连接导入文件。
