# Notes 本地知识工作区

Notes 用于在本地目录中管理 Markdown 和白板内容，把查询记录、运维步骤和项目资料放在连接工作流旁边。文件仍保存在你选择的目录中，Navop 不替代版本控制和备份。

## 选择工作目录

首次进入 Notes 时选择一个有读写权限的本地目录，也可以在设置中更换 Notes 路径。建议为不同项目使用清晰目录，并了解更换路径后旧文件不会自动移动。云盘、网络盘或版本控制目录可以使用，但同步冲突与文件锁由相应工具负责。

不要把数据库密码、SSH 私钥、主密钥或 Token 直接写入笔记。需要跨设备共享时，先确认目录自身的同步与访问策略。

## Markdown 与白板

Markdown 适合技术说明、代码片段和可移植文档，白板用于自由组织图形和思路。Markdown 默认以只读预览打开，需要精确修改时切换到源码模式；文档视图支持标准语法、受限 HTML 安全渲染，以及 Markdown 表格内图片展示，但它不是不受限制的浏览器渲染环境。创建文件时选择适合长期维护的格式，复杂内容在不同渲染器之间可能存在兼容性差异。

通过系统打开 `.md` 文件时，Navop 会进入 Notes Markdown 视图。相对图片和媒体资源以当前 Markdown 文件所在目录为基础；移动文件后应检查资源路径。白板使用独立的可编辑资料与资源目录；导出或分享预览图时，应同时保留原始白板文件，避免丢失后续编辑能力。

## 编辑、保存与快捷键

编辑器支持常用输入、选择、查找和保存快捷键，具体组合可在“设置 → 快捷键 → Notes”查看和修改。关闭未保存内容前注意提示；自动保存行为应以当前设置和格式为准，重要修改仍应主动保存并使用版本控制。

代码块、链接和图片应使用相对稳定的路径。粘贴外部内容后检查最终 Markdown 结构，避免带入不需要的 HTML、样式或外部跟踪资源。

## 导出 HTML、PDF 与 Word

安装 Notes 文档导出扩展后，可从当前文档导出自包含 HTML、PDF 或 Word DOCX。导出在 Rust WASM 扩展中完成，不依赖本机 Chrome、Office 或宿主转换库；导出前确认目录和文件名，并在目标环境打开结果检查图片、代码、Mermaid 和公式。

## 资源目录与外部修改

图片、附件和其他资源通常位于笔记目录或其资源目录。移动、重命名或删除资源会影响引用；整理前可以搜索哪些文档仍在使用。不要把超大二进制文件当作普通笔记资源长期堆积。

文件被其他编辑器修改时，重新加载前先比较本地未保存内容。Git 合并冲突、云盘冲突副本和编码变化需要在文件层解决，Navop 不会自动判断哪个版本更正确。

## 备份、兼容性与分享

定期备份整个 Notes 目录，包括隐藏配置和资源文件。Markdown 可由多数编辑器打开，但扩展语法和白板效果可能依赖 Navop 或文档渲染器扩展；分享前在目标环境预览。

对外发送笔记前检查连接名称、内网地址、SQL 结果、日志、截图元数据和个人信息。需要可复现资料时优先提供脱敏的最小示例，而不是直接打包整个工作目录。
