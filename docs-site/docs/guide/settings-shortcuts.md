# 设置、字体与快捷键

设置中心按领域分为 12 页：通用、数据库、终端、SSH、SFTP、AI、Agent、MCP、同步、账户、快捷键和关于。文件传输、远程编辑器和 ssh://、sftp://、jms:// 等链接接管分别归入 SSH、SFTP 等对应页面。修改后应在非关键会话验证；快捷键冲突或字体缺失通常不会破坏数据，但可能改变操作习惯和显示结果。

## 外观、语言与启动行为

可选择语言、启动页、浅色或深色主题，也可跟随系统。外观设置还提供窗口透明度、主题配色、自定义强调色和主题导入；应用与终端主题共享更一致的输入框、弹层、滚动条、选区与终端配色。导入主题前先确认来源可信，并在常用工作区检查文字、焦点与选中状态的对比度。

![统一主题与外观设置](/images/theme.png)

应用字体、SQL 字体、表预览字体和终端字体可以分别设置。终端与数据库共用「内置 + 自定义 + 系统已装」的等宽字体列表，选择前先确认字体覆盖了需要的字符。自定义字体支持 `.ttf`、`.otf`、`.ttc` 和 `.otc`，加载前确认授权和文件完整性。

字体不包含目标字符时会回退或显示异常；等宽字体更适合 SQL 与终端。主题切换后检查高亮、图表和远程桌面可读性。

## 连接显示与排序

「设置 → 通用 → 连接显示」中的「连接排序」控制连接列表顺序：默认按名称自然排序（IP 等数字段按数值比较、忽略大小写），也可切换为「最近使用优先（LRU）」。该设置同时作用于首页连接列表、Redis/MongoDB 工作区标签页和常驻侧栏连接树，切换后即时生效。

排序只改变显示顺序，不会修改连接本身；整理连接时不要依赖排序替代命名或分组。

## 数据库与表格偏好

数据库设置包括连接打开模式、SQL 自动保存、最大行数、表格行高和大文本打开方式。最大行数限制预览规模，不是服务器权限；提高数值会增加内存和网络开销。自动保存只保存编辑内容，不会自动提交事务。

表格显示设置可能影响可见密度，但不会改变真实字段值。处理长文本或二进制字段时选择适合的编辑器，并在提交前查看 SQL 预览。

## 终端与远程编辑设置

终端自身的全局默认值在「设置 → 终端」中调整，包括字体、主题、补全、选中复制、右键/中键粘贴、多行粘贴确认和高危命令提示。终端搜索支持区分大小写、整词和正则三种选项，其中整词匹配对中文等非 ASCII 文本同样生效。

终端工具侧边栏里的「设置」面板只作用于当前会话：字号、主题等约 20 项改动不会保存，也不会影响其他终端；面板底部提供「恢复全局默认」，可回到「设置 → 终端」的全局值。悬浮工具条与自动会话日志的开关也已迁入应用设置页。粘贴类确认集中在终端设置的安全确认区，粘贴确认弹窗同时提供「打开设置」与「不再提示」。降低安全提示前应理解 bracketed paste 与剪贴板风险。

远程文件可选择内置编辑器或扩展提供的外部编辑器，并设置默认编辑器、可执行路径和保存后自动上传。外部程序路径必须可信，自动上传前保留远端冲突检查。

## Notes、LLM 与 Public MCP

Notes 设置用于选择本地工作目录和相关编辑偏好。更换目录不会自动迁移旧资料。LLM Provider 设置管理 API key、base URL、模型和默认项；删除 Provider 前确认没有活动 Agent 依赖。

MCP 设置控制 Temporary/Persistent 服务、权限档位和 Tool Exposure。任何放宽都可能让外部客户端执行更多真实操作；修改后重新连接客户端并检查当前工具列表。

## 快捷键与冲突处理

快捷键按全局、终端、数据库、表格、远程编辑、Redis 和 Notes 等分类展示，支持清除绑定和禁用系统快捷键（全局热键关闭后，注册的系统级组合键会一并释放）。关闭当前页签的默认快捷键为 Cmd/Ctrl+Shift+W，可在设置中改绑。修改前搜索现有绑定，避免同一上下文重复；操作系统或输入法也可能抢占组合键。高风险动作不应绑定到容易误触的单键。

若快捷键无效，先确认焦点所在区域、当前平台、输入法和是否被系统占用，再恢复默认或设置新组合。团队内部可共享约定，但快捷键通常是本地个人偏好。

## 日志与更新

设置中可以查看日志路径、自动检查更新和手动检查更新。更新通道在「设置 → 关于」中切换：稳定版或测试（Beta）通道；镜像源可选自动、Cloudflare、CNB 或 GitHub，网络受限时再手动指定，避免长期依赖单一镜像。日志用于排查启动、连接、扩展、同步和 MCP 问题，可能包含本地路径、主机和错误上下文；发送前必须脱敏。

更新前保存工作、结束事务和传输，更新后核对扩展兼容性。不要通过长期关闭更新检查来规避已知安全修复，也不要在关键生产窗口未经验证地升级。
