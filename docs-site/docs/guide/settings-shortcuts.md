# 设置、字体与快捷键

设置集中管理界面、数据库、终端、远程编辑、Notes、LLM、MCP、日志和更新行为。修改后应在非关键会话验证；快捷键冲突或字体缺失通常不会破坏数据，但可能改变操作习惯和显示结果。

## 外观、语言与启动行为

可选择语言、启动页、浅色或深色主题，也可跟随系统。应用字体、SQL 字体、表预览字体和终端字体可以分别设置。自定义字体支持 `.ttf`、`.otf`、`.ttc` 和 `.otc`，加载前确认授权和文件完整性。

字体不包含目标字符时会回退或显示异常；等宽字体更适合 SQL 与终端。主题切换后检查高亮、图表和远程桌面可读性。

## 数据库与表格偏好

数据库设置包括连接打开模式、SQL 自动保存、最大行数、表格行高和大文本打开方式。最大行数限制预览规模，不是服务器权限；提高数值会增加内存和网络开销。自动保存只保存编辑内容，不会自动提交事务。

表格显示设置可能影响可见密度，但不会改变真实字段值。处理长文本或二进制字段时选择适合的编辑器，并在提交前查看 SQL 预览。

## 终端与远程编辑设置

本地 Terminal profile 可选择系统 Shell 或自定义程序。终端设置还包括字体、补全、选中复制、右键/中键粘贴、多行粘贴确认和高危命令提示。降低安全提示前应理解 bracketed paste 与剪贴板风险。

远程文件可选择内置编辑器或扩展提供的外部编辑器，并设置默认编辑器、可执行路径和保存后自动上传。外部程序路径必须可信，自动上传前保留远端冲突检查。

## Notes、LLM 与 Public MCP

Notes 设置用于选择本地工作目录和相关编辑偏好。更换目录不会自动迁移旧资料。LLM Provider 设置管理 API key、base URL、模型和默认项；删除 Provider 前确认没有活动 Agent 依赖。

MCP 设置控制 Temporary/Persistent 服务、权限档位和 Tool Exposure。任何放宽都可能让外部客户端执行更多真实操作；修改后重新连接客户端并检查当前工具列表。

## 快捷键与冲突处理

快捷键按全局、终端、数据库、表格、远程编辑、Redis 和 Notes 等分类展示。修改前搜索现有绑定，避免同一上下文重复；操作系统或输入法也可能抢占组合键。高风险动作不应绑定到容易误触的单键。

若快捷键无效，先确认焦点所在区域、当前平台、输入法和是否被系统占用，再恢复默认或设置新组合。团队内部可共享约定，但快捷键通常是本地个人偏好。

## 日志与更新

设置中可以查看日志路径、自动检查更新和手动检查更新。日志用于排查启动、连接、扩展、同步和 MCP 问题，可能包含本地路径、主机和错误上下文；发送前必须脱敏。

更新前保存工作、结束事务和传输，更新后核对扩展兼容性。不要通过长期关闭更新检查来规避已知安全修复，也不要在关键生产窗口未经验证地升级。
