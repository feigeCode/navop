# Redis 工作台

Redis 工作台支持单机、Sentinel 和 Cluster 连接，提供 Key 浏览、常见数据类型编辑、CLI、服务器信息与实时诊断。Redis 操作通常立即生效，批量删除和命名空间清理不可恢复。

![Redis 工作台](/images/redis.png)

## 创建 Redis 连接

选择单机、Sentinel 或 Cluster 模式，填写节点、端口、用户名、密码和数据库等参数。需要加密时启用 TLS；无法直连时配置 SSH 隧道。Sentinel 需要正确的服务名称和节点信息，Cluster 则应确保客户端可访问重定向后的各个节点地址。

先测试网络和认证，再保存连接。生产实例应使用受限账号，并确认扫描、INFO、Slow Log 或 Pub/Sub 等命令是否被服务器策略允许。TLS 证书验证和 SSH 隧道安全要求与数据库连接相同。

## 搜索与浏览 Key

Key 列表支持本地过滤和服务器端扫描。服务器扫描可使用 Redis glob 语法 `*`、`?` 和 `[]`；模式过宽时会产生大量结果，应缩小命名空间并控制扫描规模。列表刷新不会锁定某一时刻，活跃实例上的 Key 可能随时变化。

选中 Key 后可查看类型、TTL、内存占用和长度等信息。TTL 表示剩余过期时间；修改或移除 TTL 会改变生命周期。重命名 Key 前检查目标是否已存在以及应用是否仍引用旧名称。

## 编辑不同数据类型

String 可以查看和修改值；List 支持从头部或尾部插入及删除元素；Set 管理无序成员；Sorted Set 同时维护成员和 score；Hash 管理字段与值。提交前确认当前 Key 类型和序列位置，避免把并发更新覆盖掉。

非 UTF-8 值可能以 Raw、Hex 或 Binary 形式显示。此类内容不是普通文本，不应经过字符替换后写回；保持原始字节并使用适合的二进制工具分析。大值编辑会消耗内存和网络，应优先在副本验证。

## CLI 与服务器诊断

内置 CLI 适合执行明确命令和查看原始响应。粘贴 DEL、FLUSH、CONFIG、EVAL 或批量脚本前重新确认实例和参数。不要把未知来源命令直接用于生产。

Server Info 展示版本、客户端、持久化和复制等信息；Memory 用于观察内存结构；Slow Log 定位慢命令；命令统计反映调用频率与耗时；实时图表帮助观察趋势。诊断数据需要结合采样周期和业务负载解释，单个峰值不等于故障。

## Pub/Sub 与破坏性操作

Pub/Sub 页面可以订阅频道并观察消息，也可以按权限发布测试内容。订阅不会补发历史消息，离线期间的数据不会保留。生产频道发布前确认消息格式和消费者影响。

删除单个 Key、批量删除匹配 Key 或清理命名空间都会立即影响应用。扫描结果可能在删除期间发生变化，且 Cluster 中数据分布在多个节点。先备份或在测试实例演练，限制模式范围，并在操作后核对剩余 Key 与业务状态。
